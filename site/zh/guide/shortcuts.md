# 快捷键

以下是内置默认值。所有命令都可以在 **设置 → 快捷键** 中搜索并重新绑定，**重置** 会恢复默认。下文的 `Ctrl` 在 macOS 上通常对应 `Cmd`，单独的 Mac 快捷键会额外注明。

| 操作 | 快捷键 |
| --- | --- |
| 新建查询 | `Ctrl+Q`（macOS 为 `Cmd+Shift+N`） |
| 运行查询 | `Ctrl+R` |
| 运行选中内容 | `Ctrl+Shift+R` 或 `Ctrl+Enter` |
| 保存查询 / 设计器 / 行表单 | `Ctrl+S` |
| SQL 补全 | `Ctrl+Space` |
| 查找 | `Ctrl+F` |
| 刷新页面 | `F5` |
| 重命名表、视图、查询、备份或账号 | `F2` |
| 全选 | `Ctrl+A` |
| 复制 / 粘贴 | `Ctrl+C` / `Ctrl+V` |
| 撤销 / 重做（编辑器或表单） | `Ctrl+Z` / `Ctrl+Y`（macOS 为 `Cmd+Shift+Z`） |
| 调整编辑器字号 | `Ctrl` + 鼠标滚轮 |
| 网格编辑单元格 | `Enter` 或 `F2` |
| 在设计器网格与详情面板间切换 | `F6` |

## 表设计器

- `Tab` / `Shift+Tab` 在字段单元格间移动：列名 → 类型 → 各引擎专属单元格 → 下一行。
- `Insert` 新增字段，`Ctrl+Delete` 删除选中字段，`Ctrl+Up` / `Ctrl+Down` 上下移动字段。
- `Ctrl+F` 打开字段搜索，`Ctrl+S` 保存表。

## 列表与网格

- 方向键、`Page Up` / `Page Down`、`Home` / `End` 移动选择。
- `Enter` 打开选中对象或提交单元格；`Esc` 取消编辑或关闭当前面板。
- 在连接树搜索框中按 `Down` / `Up` 可进入筛选结果。
