# 快捷键

下表是内置默认值。每个命令都可以在 **选项 → 快捷键** 里搜索并重新绑定；**默认** 恢复全部默认值。除非单独标出 Mac 组合，**Ctrl** 在 macOS 上对应 **Cmd**。

## 通用

| 操作 | 快捷键 |
| --- | --- |
| 新建查询 | `Ctrl+Q`（macOS 为 `Cmd+Shift+N`） |
| 运行查询 | `Ctrl+R` |
| 运行选中部分 | `Ctrl+Shift+R` 或 `Ctrl+Enter` |
| 保存查询 / 设计器 / 行表单 | `Ctrl+S` |
| SQL 补全 | `Ctrl+Space` |
| 查找 | `Ctrl+F` |
| 刷新当前页 | `F5` |
| 重命名选中对象 | `F2` |
| 全选 | `Ctrl+A` |
| 复制 / 粘贴 | `Ctrl+C` / `Ctrl+V` |
| 撤销 / 重做（编辑器或表单） | `Ctrl+Z` / `Ctrl+Y`（macOS 为 `Cmd+Shift+Z`） |
| 调整编辑器字体 | `Ctrl` + 鼠标滚轮 |
| 关闭标签页 | `Ctrl+W` |
| 下一个 / 上一个标签页 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |

## 网格与表单

| 操作 | 快捷键 |
| --- | --- |
| 编辑单元格 | `Enter` 或 `F2` |
| 提交并向下 / 向上移动 | `Enter` / `Shift+Enter` |
| 暂存并向右移动 | `Tab` |
| 放弃单元格编辑 | `Esc` |
| 保存行 | `Ctrl+S` |
| 删除选中行 | `Delete` |
| 新建记录 | 在最后一行按 `Down`，或点工具栏 `+` |
| 表单字段切换 | `Tab` / `Shift+Tab` |

## 表设计器

- `Tab` / `Shift+Tab` 在字段单元格之间移动：列名 → 类型 → 各引擎单元格 → 下一行。
- `Insert` 添加字段，`Ctrl+Delete` 删除选中字段，`Ctrl+Up` / `Ctrl+Down` 移动字段。
- `Ctrl+F` 打开字段搜索，`Ctrl+S` 保存表，`F6` 在网格 ⇄ 详情面板之间切换。
- 在单元格编辑器里，`Up` / `Down` 提交并移动一行；`Left` / `Right` 留给光标。

## 列表与连接树

- 方向键、`Page Up` / `Page Down` 和 `Home` / `End` 移动选择。
- `Enter` 打开选中对象或提交单元格；`Esc` 取消编辑或关闭当前面板。
- 在连接树搜索框里，`Down` / `Up` 把焦点移到过滤结果。
- `Ctrl` / `Cmd` + 单击切换一行，`Shift` + 单击从锚点扩展，橡皮筋拖动选择经过的所有行。

## 自定义

打开 **选项 → 快捷键**，搜索命令，点击按键框后按下新组合。冲突会标在列表里。`↺` 恢复单个默认绑定，`✕` 清除绑定，页面上的 **默认** 恢复全部命令。
