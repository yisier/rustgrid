# Keyboard shortcuts

These are the built-in defaults. Every command can be searched and rebound in **Options → Shortcuts**; the **Reset** button restores the defaults. **Ctrl** means **Cmd** on macOS unless a separate Mac shortcut is shown.

## General

| Action | Shortcut |
| --- | --- |
| New query | `Ctrl+Q` (`Cmd+Shift+N` on macOS) |
| Run query | `Ctrl+R` |
| Run selection | `Ctrl+Shift+R` or `Ctrl+Enter` |
| Save query / designer / row form | `Ctrl+S` |
| SQL completion | `Ctrl+Space` |
| Find | `Ctrl+F` |
| Refresh page | `F5` |
| Rename selected object | `F2` |
| Select all | `Ctrl+A` |
| Copy / paste | `Ctrl+C` / `Ctrl+V` |
| Undo / redo (editor or form) | `Ctrl+Z` / `Ctrl+Y` (`Cmd+Shift+Z` on macOS) |
| Editor font size | `Ctrl` + mouse wheel |
| Close tab | `Ctrl+W` |
| Next / previous tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` |

## Grid and form

| Action | Shortcut |
| --- | --- |
| Edit cell | `Enter` or `F2` |
| Commit and move down / up | `Enter` / `Shift+Enter` |
| Stage and move right | `Tab` |
| Discard the cell edit | `Esc` |
| Save the row | `Ctrl+S` |
| Delete selected rows | `Delete` |
| New record | `Down` on the last row, or the toolbar `+` |
| Switch form fields | `Tab` / `Shift+Tab` |

## Table designer

- `Tab` / `Shift+Tab` walks the field cells: name → type → every engine cell → next row.
- `Insert` adds a field, `Ctrl+Delete` deletes the selected fields, `Ctrl+Up` / `Ctrl+Down` moves them.
- `Ctrl+F` opens the field search, `Ctrl+S` saves the table, `F6` switches grid ⇄ detail panel.
- In a cell editor, `Up` / `Down` commits and moves one row; `Left` / `Right` stay with the caret.

## Lists and tree

- Arrow keys, `Page Up` / `Page Down` and `Home` / `End` move the selection.
- `Enter` opens the selected object or commits a cell; `Esc` cancels the editor or closes the current panel.
- In the connection tree, `Down` / `Up` from the search box moves into the filtered results.
- `Ctrl` / `Cmd` + click toggles a row, `Shift` + click extends from the anchor, and a rubber-band drag selects every intersected row.

## Customising

Open **Options → Shortcuts**, search for a command, click its key field and press the new combination. A conflict is marked in the list. `↺` restores one default, `✕` removes a binding, and the page's **Default** restores every command.
