# История изменений

[English](CHANGELOG.md) | [简体中文](CHANGELOG_zh.md) | Русский

Все заметные изменения RustGrid документируются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), проект следует
[семантическому версионированию](https://semver.org/lang/ru/).

Названия элементов интерфейса приводятся так, как их показывает приложение на русском языке;
английские строки — в [`CHANGELOG.md`](CHANGELOG.md), китайские — в
[`CHANGELOG_zh.md`](CHANGELOG_zh.md).

## [0.1.5] - 2026-11-02

### Добавлено

- В списке ключей Redis появился столбец «Группа» (префикс ключа до первого двоеточия), по нему
  список сортируется по умолчанию.
- Редактор запросов подсвечивает команды и ключи Redis и предлагает их дополнение.
- Контекстное меню пространства имён Redis в дереве предлагает «Новый ключ» и «Обновить».
- Представление JSON на странице ключа подсвечивает синтаксис.

### Изменено

- В меню базы данных Redis «Новый ключ» заменил «Выполнить SQL-файл...» и «Дамп SQL-файла», а во
  вкладках запросов Redis скрыта команда «Форматировать SQL».
- «Новый ключ» подставляет префикс выбранного пространства имён.
- При листании, сортировке и фильтрации сетка сохраняет горизонтальную прокрутку, а сортировка
  сохраняет ширину столбцов.
- Полоса прокрутки дерева подключений появляется только при прокрутке и больше не перекрывает
  разделитель.
- Редакторы без номеров строк больше не оставляют пустое поле для сворачивания.

### Исправлено

- Щелчок по пространству имён Redis в дереве больше не закрывает приложение.
- Сохранение строкового ключа берёт текущий текст редактора и подтверждается сообщением
  «Сохранено».
- Выделено только текущее пространство имён Redis; ранее отфильтрованное больше не остаётся
  выбранным.

## [0.1.4] - 2026-11-01

### Добавлено

- Подключения Redis (отдельный сервер, Sentinel и кластер): ключи по пространствам имён, у каждого
  видны тип, TTL, память и предпросмотр значения и есть своя страница (RAW/JSON для строк,
  редактируемые таблицы для коллекций), а также «Новый ключ», «Задать TTL», удаление
  и переименование.
- Синхронизация структуры позволяет выбрать исходную и целевую схему для SQL Server и PostgreSQL.

### Изменено

- На странице «Общие» подключение включает TLS/SSL и туннель переключателями, а их вкладки
  появляются только при включении.
- Кнопка раскладки полей в сетке данных называется «Поля» (была «Фильтр»).
- Колесо мыши прокручивает списки объектов в виде плитки по горизонтали.
- Поля страницы и лимита записей поддерживают ввод, вставку и IME, а стрелки меняют лимит на 100.
- Импорт продолжается после ошибочной строки, а «Бекапы» в дереве раскрываются до файлов.
- Текст списка изменений в «О программе», журнала синхронизации и диалогов ошибок можно
  выделять и копировать.

### Исправлено

- Контекстное меню сохранённого запроса или бекапа в дереве больше не закрывает приложение.
- Закрытие базы данных закрывает её вкладки, а список объектов следует за выбором в дереве.
- Автосохранение ячейки при потере фокуса подтверждается сообщением.
- Панель фильтров и дерево подключений соответствуют активному представлению.
- Ctrl+щелчок, убирающий ячейку из «Выделить всё», сохраняет остальное выделение.
- Длинные имена бекапов полностью видны в сетке плиткой.

## [0.1.3] - 2026-10-28

### Добавлено

- В подключении MySQL появился необязательный режим совместимости StarRocks
  (Дополнительно → Режим совместимости): работают просмотр, постраничный вывод и редактирование,
  а неподдерживаемые разделы (пользователи, функции, конструктор таблиц, резервное копирование)
  скрыты.
- «Экспорт результатов» на панели запроса экспортирует один или несколько наборов результатов;
  несколько наборов записываются листами одной книги `.xlsx`.
- При экспорте таблицы можно выбрать все записи или текущую страницу с отфильтрованными и
  отсортированными строками.

### Изменено

- Если «Восстанавливать при запуске» выключено, соединения, базы данных и группы при запуске
  свёрнуты.
- В диалоге резервного копирования кнопка «Сохранить» доступна только после изменения имени или
  выбранных объектов.

### Исправлено

- Панель фильтров и применённое условие WHERE синхронизированы, поэтому выбранный столбец — тот,
  по которому идёт фильтрация.
- Столбцы TIMESTAMP в MySQL показывают время сервера, а не необработанные байты.

## [0.1.2] - 2026-10-26

### Добавлено

- Конструктор таблиц выделяет поля как сетка данных: перетаскивание или Shift расширяет диапазон,
  Ctrl переключает ячейки, Ctrl+A выделяет всё, щелчок по заголовку строки выделяет строку целиком,
  а Ctrl+C копирует выделение.

### Изменено

- В контекстном меню сетки данных больше нет пункта «Вставить строку».
- Удаление, «Вверх» и «Вниз» в конструкторе таблиц действуют на все выделенные строки полей.

### Исправлено

- Изменение порядка полей в конструкторе таблиц сохраняется, а не выдаёт «Нет изменений для
  применения».
- Щелчок по основной вкладке очищает поиск этого списка и снова показывает все объекты;
  «Сохранять поиск по объектам» теперь действует только при смене базы данных и соединения.
- Бекапы: «Удалить», «Восстановить» и «Извлечь» действуют на выбранную строку текущей базы данных
  и не затрагивают одноимённый файл в другой базе.
- Бекапы: прошедшее время продолжает обновляться во время долгого запуска.
- Бекапы: после запуска выбирается только что записанный файл, а вставка файла синхронизирует
  выделение в списке.
- При вставке скопированных записей сохраняются значения NULL, поэтому числовые столбцы
  сохраняются, а не завершаются ошибкой неверного значения.
- Сохранение изменений таблицы подтверждается сообщением, а «Сохранить» / Ctrl+S сообщает,
  что сохранять нечего.
- Обновление таблицы подтверждается сообщением о завершении.
- Удаление записей из контекстного меню сетки данных больше не закрывает приложение.

## [0.1.1] - 2026-10-22

### Добавлено

- Русский интерфейс и отдельная история изменений
  ([#22](https://github.com/yisier/rustgrid/pull/22)).
- Параметры → Общие: «Режим одного клика» — соединения, базы данных, таблицы и другие объекты
  открываются одним щелчком ([#14](https://github.com/yisier/rustgrid/issues/14)).
- Параметры → О программе показывают заметки о новой версии на языке интерфейса.

### Изменено

- Все окна используют общий заголовок с системными кнопками окна
  ([#21](https://github.com/yisier/rustgrid/issues/21)).

### Исправлено

- MySQL 5.7 и другие серверы без `GENERATION_EXPRESSION`: конструктор таблиц и синхронизация
  структуры больше не завершаются ошибкой 1054
  ([#20](https://github.com/yisier/rustgrid/issues/20)).
- Щелчок по категории «Таблицы» или «Представления» больше не заставляет список объектов прыгать и
  перестраиваться ([#23](https://github.com/yisier/rustgrid/issues/23)).
- Длинные русские подписи больше не обрезают элементы управления синхронизации.
- Китайский интерфейс снова показывает названия категорий на китайском, а не на английском.
- При закрытии окна с несохранённой работой подтверждение запрашивается всегда, включая Alt+F4.

## [0.1.0] - 2026-10-21

### Добавлено

- Вкладка «Синхронизация» (после «Бекапов»): сравнение исходной базы с целевой — в том числе между
  разными СУБД — и применение структуры, данных, обоих или полной копии, со статусом по каждой
  таблице, построчной разницей, предпросмотром SQL, журналом выполнения и сохраняемыми
  конфигурациями.
- Конструктор таблиц поддерживает ограничения-исключения и правила перезаписи PostgreSQL, триггеры,
  партиционирование MySQL/MariaDB, а также редактирование идентификационных столбцов PostgreSQL
  (способ генерации, начало, шаг).
- Конструктор предлагает типовые значения по умолчанию для выбранного типа столбца, а сетка полей
  перемещается как сетка данных (стрелки, Tab, Enter/F2).
- «Очистить» и «Усечь» действуют сразу на все выбранные таблицы.

### Исправлено

- PostgreSQL: результаты запросов снова показывают наборы результатов
  ([#12](https://github.com/yisier/rustgrid/issues/12)), а конструктор таблиц завершается
  ([#15](https://github.com/yisier/rustgrid/issues/15)).
- PostgreSQL: ORDER BY сохраняет исходный тип столбца, а не сортирует числа и даты как текст.
- Подсказки в полях поиска и фильтра следуют за сменой языка интерфейса
  ([#19](https://github.com/yisier/rustgrid/issues/19)).
- Загрузка страницы сетки больше не сдвигает строки вниз и обратно.
- Меню, открытое по указателю, появляется под ним, поле переименования группы в дереве соединений
  снова принимает ввод, а список объектов перерисовывается сразу после смены темы.
- Длинные подписи переносятся в окне «Параметры» и во всплывающем окне параметров синхронизации.

## [0.0.15] - 2026-10-19

### Добавлено

- Подробные списки сортируются: щелчок по заголовку столбца упорядочивает по нему, повторный — в
  обратном порядке — в «Таблицах», «Представлениях», «Функциях», «Пользователях», «Бекапах» и
  сохранённых запросах.
- Параметры → Редактор: «Ctrl + колесо мыши изменяет размер шрифта», включено по умолчанию —
  удерживайте Ctrl и прокручивайте колесо над редактором запросов, чтобы увеличить или уменьшить
  шрифт.
- Параметры → Общие: «Восстанавливать при запуске», включено по умолчанию — вкладки запросов,
  соединения, открытые базы данных и вкладки таблиц прошлого запуска возвращаются.
- Вкладки результатов запроса листаются кнопками ← / →, когда наборы результатов не помещаются.

### Изменено

- Все подробные списки стали компактнее (строки 28px), поэтому в панель помещается больше строк.
- Параметры → Общие: переключатель поиска по объектам теперь называется «Сохранять поиск по
  объектам», включён по умолчанию, и каждый список хранит свой текст — поиск по таблицам больше не
  фильтрует представления, функции или запросы.
- Настройки редактора (шрифт, размер, «Показывать номера строк», «Перенос слов») применяются к уже
  открытым редакторам, а не только к вкладкам, открытым после изменения.

## [0.0.14] - 2026-10-18

### Добавлено

- Параметры → Сочетания клавиш: каждая комбинация — команда, которую можно переназначить — найдите
  её в списке, щёлкните поле и нажмите новые клавиши; ↺ восстанавливает значение по умолчанию,
  ✕ удаляет его, а конфликт помечается в обеих строках.
- Дерево соединений и список объектов управляются с клавиатуры: стрелки, Page Up / Page Down,
  Home / End, ← / → для сворачивания и разворачивания, Enter, F2, а ввод имени переходит к нему.
- Вкладки: Ctrl+Q открывает запрос, Ctrl+W закрывает вкладку, Ctrl+Tab / Ctrl+Shift+Tab переключают
  их в порядке панели вкладок, а меню вкладки показывает сочетание для каждого действия.
- Сетка таблицы перемещается как электронная таблица (стрелки, Page Up / Page Down, Home / End,
  Ctrl+Home / Ctrl+End, Tab, Shift расширяет выделение), F5 перезагружает на месте, а F2 открывает
  редактор значения под сеткой.
- Редактор запросов: Ctrl+K или Ctrl+/ комментирует и раскомментирует, Ctrl+D дублирует, Ctrl+T
  меняет строки местами, Alt+↑ / Alt+↓ перемещают их, а «Форматировать SQL» можно отменить.
- Запросы выполняются оператор за оператором в одном соединении: каждый сохраняет свой результат,
  ошибку и время, а вкладка «Информация» записывает их и отмечает сбойный оператор.
- Дамп MySQL с `DELIMITER` и телами `CREATE PROCEDURE` выполняется так же, как в клиенте mysql.
- При следующем запуске открываются вкладки запросов (с несохранённым текстом), соединения,
  открытые базы данных и вкладки таблиц, которые были открыты.
- Параметры → Общие: лимит операторов за запуск, остановка на первой ошибке и сохранение поиска по
  объектам между вкладками; щёлкните настройку правой кнопкой, чтобы скопировать её имя или путь.

### Изменено

- Комментарии как в Navicat: `--`, `//`, `#` (MySQL) и незакрытый `/*` комментируют остаток строки с
  пробелом или без, а закомментированное никогда не отправляется на сервер.
- Автодополнение предлагает сначала столбцы и псевдонимы текущего оператора там, где ожидается
  столбец.
- Щелчок по уже выделенной ячейке открывает её редактор; ← / → внутри ячейки остаются в ней.
- «Закрыть другие вкладки» и «Закрыть все» назначены на Ctrl+Alt+W и Ctrl+Shift+W и переназначаются
  как любая команда.

### Исправлено

- `DELIMITER GO` больше не завершает оператор внутри слова вроде `CATEGORY`.
- `END$$` завершает оператор, поэтому процедура, записанная без пробела перед разделителем,
  разбивается правильно.

## [0.0.13] - 2026-10-16

### Добавлено

- Конструктор каждого движка показывает свои возможности: SQL Server получает «Сопоставление» /
  «Разреженное», «Размер» / «Масштаб» / «Вычисляемый» и вкладки «Уникальные ключи» / «Проверки»;
  SQLite, PostgreSQL и Oracle теряют недоступные страницы.
- Конструктор SQL Server также редактирует уникальные ограничения и ограничения-проверки.
- Редактор полей индекса — это список полей Navicat: отметьте поля, перетащите их в нужном порядке,
  задайте сортировку / префикс.
- Сетка полей конструктора перемещается по Tab / Shift+Tab, а выпадающий список типа работает с
  клавиатуры.
- Панели предпросмотра SQL можно выделять и копировать — в конструкторе, окне пользователя и
  «Правах на объекты».

### Изменено

- Столбец индекса несёт собственные параметры (`DESC`, префикс MySQL) и сохраняет их.
- Ячейки «Поля» / «Поля ссылки» — выпадающие списки: щёлкните ячейку, кнопки «...» нет.
- Детали поля, список полей и страница «Параметры» конструктора больше не повторяют форму MySQL на
  каждом движке.
- Светлая палитра выглядит как у Navicat: белые панели и видимые разделители вместо серых заливок.
- Сетка «Индексы» перечисляет только вторичные индексы; первичный ключ управляется на вкладке
  «Поля».
- Полоса перед первым полем стала уже, а подписи конструктора выровнены по одному левому краю.
- «Тип индекса» показывает собственный тип движка; «Метод индекса» появляется только там, где у
  движка их несколько.
- Вкладка «Триггеры» конструктора удалена — она могла показывать только пустую сетку.

### Исправлено

- Сетки конструктора прокручиваются колесом мыши.
- «Автоувеличение» появляется только у типов, которые поддерживает движок, и никогда не бывает
  неактивным элементом.
- Сохранение структуры таблицы сообщает об успехе и закрывает открытый редактор ячейки; сохранение
  без изменений так и говорит.
- Изменённый индекс сохраняется на всех движках.
- Добавление поля, уникального ключа или проверки начинается с имени, прокручивается в вид и готово
  к вводу.
- Редактор полей индекса больше не открывается за пределами экрана, а его столбец «Тип индекса» не
  обрезается.
- Предпросмотр SQL новой таблицы работает до того, как у неё появилось имя.

## [0.0.12] - 2026-10-15

### Добавлено

- **Журнал изменений** в «Параметры → О программе»: когда проверка находит более новый выпуск,
  панель показывает заметки этой версии — что даст установка, на языке интерфейса — и полностью
  скрывается, пока текущая сборка уже является новейшим выпуском. Репозиторий хранит журнал на
  английском и китайском, а задача выпуска публикует раздел каждой версии как заметки к выпуску (и
  завершается ошибкой, если раздела нет).
- Автодополнение SQL сопоставляет нестрого: кандидат находится по точному имени, префиксу, любой
  части или подпоследовательности, ближайшие совпадения идут первыми; таблицы — сразу после `FROM` /
  `JOIN` / `INTO` / `UPDATE` / `TABLE`, а повседневные ключевые слова (в порядке частоты ввода) —
  перед остальным языком. `Tab` принимает выделенный вариант и по-прежнему делает отступ, когда
  список не открыт.
- Сочетания клавиш запуска в редакторе запросов настраиваются в «Параметры → **Сочетания клавиш**»:
  щёлкните поле, нажмите комбинацию, и «ОК» применит её («По умолчанию» возвращает Ctrl+R /
  Ctrl+Shift+R как в Navicat). Ctrl+R выполняет весь редактор, Ctrl+Shift+R — только выделение, а
  Ctrl+Enter остаётся синонимом запуска.

### Исправлено

- Ячейки и заголовки сетки получили горизонтальные отступы 6px, поэтому значение больше не
  прилипает к разделителю предыдущего столбца и его тексту (issue #5).
- Редактор учётной записи MySQL показывает базу, на которую у записи есть только право
  (`GRANT USAGE ON db.* WITH GRANT OPTION`), как её показывают Navicat и `SHOW DATABASES`.
- **Закрыть соединение** закрывает вместе с ним окно учётной записи и окно «Права на объекты» этого
  соединения и очищает список «Пользователи», чтобы ни одно окно не редактировало учётную запись
  через мёртвое соединение.

  когда указатель уходит; доработки взаимодействия с фильтром и деревом; пустая сетка отображается
  как полная пустая таблица.

## [0.0.1] - 2026-10-08

Первый выпуск.

### Добавлено

- Каркас рабочего пространства Cargo: независимый от движка `rustgrid-core`, драйвер MySQL, хранилище
  конфигурации и приложение GPUI; лицензия Apache-2.0.
- Управление соединениями (создание / изменение / удаление, подключение, запрос пароля,
  зашифрованные секреты) и базами данных (набор символов / сопоставление).
- Таблицы и представления с постраничной, редактируемой сеткой — вставка, множественное выделение
  как в Excel, сортировка, конструктор фильтров, изменяемая ширина столбцов и сумма выделенных
  числовых ячеек.
- Редактор SQL с подсветкой синтаксиса, автодополнением ключевых слов/таблиц, «Форматировать SQL»,
  Explain, сохранёнными именованными запросами, вкладками нескольких результатов и окном извлечения
  SQL.
- Бекап / восстановление с собственным контейнером `.rgbak` и мастера импорта / экспорта
  (Excel / CSV / TXT / `.xlsx` / `.sql`).
- Управление пользователями и правами, конструкторы процедур и представлений, а также единое
  взаимодействие со списками в стиле Проводника на всех страницах.
- Драйверы: MySQL / MariaDB, SQLite, SQL Server, PostgreSQL, Oracle и универсальный ODBC-движок,
  загружаемый во время работы (DB2, Dameng, ...).
- Оформление gpui-kit / shadcn со светлой, тёмной и системной темами, на английском и 简体中文.
- Переносимые сборки GitHub Releases с самообновлением.
